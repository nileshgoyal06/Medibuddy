# Medicine Search App

A simple React application to search medicines using the FDA Drug Label API and view their details.

## Features

- Search medicines by name
- Display matching medicines
- View medicine details
- Loading state

## Tech Stack

- React.js
- TypeScript
- Vite
- FDA Drug Label API

## Steps to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/nileshgoyal06/Medibuddy.git
2. Go to the project folder
cd Medibuddy
3. Install dependencies
npm install
4. Create .env file
VITE_API_URL=https://api.fda.gov/drug/label.json
5. Run the application
npm run dev
